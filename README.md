# Sweet Spot tablet app — downloads

**Install / update the tablet app** (open this link on the tablet):

https://github.com/bcuproject/sweet-spot-downloads/raw/main/sweet-spot-tablet.apk

- Always the newest version. Install it straight over the old app — **do not uninstall first** (that wipes saved orders and settings).
- If Android asks, allow your browser to install apps.
- The app needs a tablet key from the Sweet Spot Cloud to receive orders.

Older tablets (32-bit): https://github.com/bcuproject/sweet-spot-downloads/raw/main/sweet-spot-tablet-arm32.apk
